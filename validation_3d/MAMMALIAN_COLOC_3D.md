# Mammalian HCT116 G3BP1↔PABPC1 colocalization: 3D vs MIP

Pair G3BP1_vs_PABPC1, whole-cell compartment (matches published run), n = 3 control + 3 arsenite z-stack reps (paired MIP–3D n = 6 reps); published-2D secondary axis n = 3 control + 4 arsenite. **Arsenite > control does NOT hold in 3D for any metric:** Pearson R 0.786 vs 0.790 (Mann–Whitney p = 1.0), Manders M1 ~1.000 vs 1.000 (p = 0.35), M2 1.000 vs 1.000 (p = 0.50) — whole-cell coloc is already saturated in both conditions, so the published arsenite-enrichment is not recovered at this compartment in 3D (or, by the same measure, in MIP). MIP vs 3D differs by metric: **Pearson R is inflated by MIP** (sign +, small, per-rep median Δ +0.049, Wilcoxon p = 0.44, NS); **Manders M1 is depressed by MIP** (sign −, large, median Δ −0.21 / mean −0.39, with arsenite reps collapsing ~−0.9, p = 0.031); **Manders M2 is mildly depressed** (sign −, median Δ −0.05, p = 0.25, NS). The projection also flips one direction: in M2, 3D shows control = arsenite (both 1.000) but MIP makes arsenite (1.000) > control (0.876) — a MIP-manufactured difference.

**Methods statement:** Colocalization (Pearson R and Manders M1/M2) was computed natively in 3D from the raw z-stacks within each cell's whole-cell volume; maximum-intensity projection of the identical masks and voxels shifts these values metric-dependently — inflating Pearson R (~+0.05) and substantially depressing Manders M1 (~−0.2 to −0.9 in arsenite) — and can even reverse the arsenite-vs-control direction for Manders M2, confirming that MIP-based coloc is not a faithful proxy for the 3D measurement.
